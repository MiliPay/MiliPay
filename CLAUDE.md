# MiliPay (BioPay monorepo)

Palm payments for Nigeria: a mobile app (`mobile-app`), admin, support,
agent and merchant portals (shared pages in `packages/shared`), a marketing
website (`website`) and a Supabase backend (`supabase/`).

Current status, live URLs, the dev/staging/production plan and what's
waiting on whom:

@docs/HANDOFF.md

Project rules (currency in naira, conventions, architecture notes) are in
`GEMINI.md`; they apply here too.

Keep `docs/HANDOFF.md` up to date at the end of each piece of work, and
commit it with that work, so the next session or machine can carry on.
